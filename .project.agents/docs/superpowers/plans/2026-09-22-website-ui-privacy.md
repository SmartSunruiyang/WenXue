# 官网 UI、文档与隐私页更新

- 范围：当前官网 WebsiteSite，依据 `../../context/ARCHITECTURE.md §2.5` 与 `../../context/UIUX.md`。
- 用户需求：桌面端同款纯白背景；主标题「Agent，直接操作浏览器」；文档右侧增加隐私；新增隐私协议 / 用户须知；重新设计文档。
- 工作树：隔离于现有桌面文档改动，不修改原工作区的未提交内容。

## 实施

1. 同步官网模块说明与 UI 规范；保持静态 React / Vite 及现有 hash 路由，无新增依赖。
2. 首页仅改背景为白色及更新标题文字，恢复原首页 / 字体动效、原字体与控件，以及原顶部导航的透明到胶囊收束设计；在原桌面 / 手机导航中追加隐私入口。
3. 文档使用中文分组、搜索、章节目录、教程、问题排查、开发者说明；去除素材占位与过时承诺。
4. 隐私页参考 OpenAI 官方政策的信息层级；依据实际产品数据流独立编写中文协议与用户须知。使用用户已确认的运营主体 `Askwenxue.com opc` 与联系邮箱 `contact@askwenxue.com`；未确认的数据保留、供应商处理及官网托管规则保留为发布前待核对项。
5. 验证生产构建、已有测试、路由链接 / 前进后退、搜索 / 无结果、政策切换、桌面及移动端布局、键盘与减少动态效果；写执行日志。

## 验收

- 首页、文档、隐私均为白底且手机无横向溢出。
- 新地址支持直接访问与刷新；文档和政策锚点不覆盖主路由。
- 隐私与须知完整可读，真实数据流与未确认运营信息明确区分。
- 本任务交付代码与本地预览，不进行生产部署。
