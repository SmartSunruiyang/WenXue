# 无感用户会话交接实施计划

设计依据：[无感用户会话交接设计](../specs/2026-09-22-invisible-session-handoff-design.md)

- [x] 1. 固化当前运行时契约
  - 更新 ARCHITECTURE、TECH-INFRA 与 UIUX 中的交接标签顺序、销毁和日志约束。
  - _要求：1、2、3、4_
- [x] 2. 支持有序启动 URL
  - 将 LaunchConfig / BrowserSupervisor 的单 URL 输入改为有序 URL 列表。
  - 让 DesktopBridge 同时打开前台新标签页和后台交接页。
  - _要求：1、4_
- [x] 3. 让交接通道无可见 UI并自动销毁
  - 将交接页改为空白传输页，并在完成回传后请求扩展关闭发送方标签。
  - 为扩展外部消息处理增加来源校验和发送方标签销毁测试。
  - _要求：1、2、5_
- [x] 4. 增加桌面脱敏日志
  - 记录开始、成功、拒绝和异常，不记录凭据、nonce URL 或 session 正文。
  - _要求：3、5_
- [x] 5. 验证并记录
  - 运行定向测试、类型检查、构建和可用的真环境浏览器检查。
  - 写实施日志，注明未提交状态及任何真环境缺口。
  - _要求：1、2、3、4、5_
