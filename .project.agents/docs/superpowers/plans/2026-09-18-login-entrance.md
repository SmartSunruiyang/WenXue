# 登录页品牌入场动效

- 归属：当前运行时 `ARCHITECTURE.md` 的 ConsoleUI；视觉权威为 `docs/context/UIUX.md`。
- 用户要求：未登录进入时，问字 Logo 居中浮现，随后左移，slogan 从 Logo 后向右滑出；品牌退场后欢迎语与登录表单浮现。表单顶部移除常驻品牌区，其余组件保持现状。
- 复用 `logo.png` 与 `slogan.png`，不增加资源、运行时依赖或认证逻辑。
- 节奏：Logo 约 480ms 浮现，500ms 起左移，620ms 起展开 slogan，1800ms 起品牌淡出，2100ms 显示表单并在 420ms 内浮现。
- 仅 AuthScreen 挂载时播放；登录 / 注册切换、输入、错误与窗口状态更新不重播。
- 动画期间不挂载可交互表单；结束后恢复原自动聚焦。减少动态效果时直接展示表单；运行期间开启该偏好也立即结束入场。计时器与偏好监听在卸载时清理。
