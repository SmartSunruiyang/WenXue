# Beta 版本与更新提示修复计划

所属运行时：当前 Electron + CfT。依据 `../../context/ARCHITECTURE.md` 的 DesktopUpdateService、DesktopBridge、ConsoleUI 契约，以及 `../../context/TECH-INFRA.md` 的更新与打包规则。

## 现象与范围

- 缺少内置 Ed25519 更新公钥的打包版在启动时进入不可重试的更新错误；ConsoleUI 的顶部提示没有关闭动作。
- 桌面、插件、官网的产品版本来源与展示不一致。此次面向用户的版本标识为 `0.0.1beta`。

## 实施

1. 为无候选更新错误提示提供关闭按钮，关闭后保留“关于问学”的状态说明；用户主动重新检查可再次看到提示。
2. 产品包版本统一为合法语义版本 `0.0.1-beta`。界面显示 `0.0.1beta`；Chrome 插件清单使用合法数值版本并提供 `version_name`。
3. beta 包未显式指定更新通道时默认使用 beta；CI 显式通道仍优先。
4. 更新当前运行时的版本/提示文档并写实施日志。

## 验证

- UI 回归：提示可关闭、错误详情仍可在“关于”查看、beta 版本可见。
- IPC 回归：桌面读到插件 `version_name`。
- 构建检查：插件 manifest、桌面输出、官网产物与打包安装器版本一致；运行目标测试和类型检查。
