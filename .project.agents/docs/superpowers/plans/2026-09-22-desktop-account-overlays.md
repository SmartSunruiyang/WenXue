# 桌面账号资料与交互优化实施计划

- 日期：2026-09-22
- 依据：用户六项要求、当前 ARCHITECTURE §2.1 ConsoleUI / DesktopBridge / MainBootstrap、UIUX §5–7、目标 PRD F10。
- 基线：`f74986d`；开始前工作区干净。

## 设计与边界

- 注册、主页左栏、头像菜单、设置「我的」使用同一账号的头像，统一为圆角方形。永久头像引用仍存 CloudBase Auth picture，展示解析为 HTTPS URL。
- 设置新增「我的」：昵称、头像、只读 UID 与邮箱、退出登录。资料保存成功同步 App 的公开账号状态；失败保留草稿。沿用既有认证适配器与安全退出顺序。
- ConsoleUI 内部增加账号资料视图及复用弹层组件，不新增业务模块、第三方运行时依赖或认证服务。
- 菜单、选择器和询问弹窗均自绘；菜单支持键盘导航、Escape、外部点击和焦点恢复，通过 portal 避免裁切。展开约 160–180ms 淡入与小幅位移，尊重减少动态效果。
- 所有下拉箭头预留至少 12px 右侧间距；输入与交互控件以低强度柔光替代黑色轮廓，保留高对比度模式可见焦点。
- MainBootstrap 关闭窗口的安全决策仍在主进程；通过 DesktopBridge 的类型化事件/应答在 renderer 展示询问与失败，取消或窗口/renderer 失效时不执行退出。
- 保留系统文件选择能力；该任务替换询问、确认与下拉弹层，不改变 OS 文件访问或更新安装交接。
