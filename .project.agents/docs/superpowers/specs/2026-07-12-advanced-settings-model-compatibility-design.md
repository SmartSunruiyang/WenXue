# 高级设置与模型工具选择兼容设计

> 2026-09-18 视觉规范更新：本文的功能 / 运行时契约继续有效；所有颜色、排版、布局、动效和组件样式以 [统一 UIUX](../../context/UIUX.md) 为准，旧视觉示例仅为历史。

## 范围

本变更优化当前问学插件基线：模型协议兼容由运行时自动处理，`llms.txt` 保持显式实验开关，
“包含所有标签页”默认开启。并行存在的 PRD v0.2 浏览器化草案不属于本任务，按用户确认不修改。

## 用户故事

- 作为普通用户，我不需要理解 `named tool_choice`，模型不兼容时问学会自动恢复。
- 作为高级用户，我可以在可信网站上选择启用 `llms.txt` 上下文。
- 作为用户，我开始任务时默认允许 Agent 使用当前窗口内可操作的全部标签页。

## 验收标准

1. 当模型以明确的 400/422 类型或格式错误拒绝 named `tool_choice` 时，问学应立即用
   `required` 重试一次，并按“规范化接口地址 + 模型名”记住该能力限制。
2. 当同一模型能力记录仍有效时，问学应直接使用 `required`；当接口地址或模型名不同时，
   记录不得串用。
3. 当错误与 named `tool_choice` 无关、属于思考模式限制、鉴权、限流或服务端错误时，问学
   不得学习错误能力。
4. 能力记录应存于 `chrome.storage.local`，带版本与 30 天有效期，不包含 API Key、鉴权信息
   或错误正文。
5. options 设置页不得再展示 `named tool_choice` 开关；旧配置字段不得重新进入运行时或保存结果。
6. `llms.txt` 应默认关闭，并在开关下说明仅建议在可信网站开启。
7. 当未保存“包含所有标签页”设置时，设置页和运行时均应视为开启；显式保存 `false` 时仍应关闭。
8. 主 Agent、视觉观察与学习通结构化请求应共享自动兼容结论，同时保留学习通现有思考模式
   `auto` 降级规则。

## 技术设计

- `@page-agent/llms` 提供严格的 named-tool 错误识别与能力标记函数；`OpenAIClient` 在确认实际
  发出了 named 选择后，标记当前配置并递归重建一次请求，使 model patch 与请求变换重新执行。
- `RuntimeAgentModels` 从独立存储键加载能力记录，把内部 `disableNamedToolChoice` 初值与持久化
  回调注入文本、视觉模型；各配置对象与 API Key 保持独立，同一 endpoint/model 共享实时能力状态。
- `visualObserve` 与 `chaoxing/llm` 使用相同识别/标记函数；学习通先保留其 Qwen thinking 分支，
  仅对其他明确 named 格式错误使用 `required`。
- 旧的用户级全局开关仅迁移删除，不转化为永久模型能力；必要时首次调用会自动探测并恢复。

## 非目标

- 不修改并行的 PRD v0.2 草案。
- 不改变 `llms.txt` 的抓取、截断或缓存协议。
- 不新增隐私提示或任务级标签页授权流程。
- 不改变 CloudBase Gateway 的上游错误透传格式。
