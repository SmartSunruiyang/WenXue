# 浅色登录与两步注册

- 状态：用户已确认，2026-09-22；注册顺序为先密码、后头像昵称。
- 归属：当前运行时 ConsoleUI；权威为 UIUX §7、PRD F10、ARCHITECTURE ConsoleUI。
- 基线：已有邮箱认证改动已提交为 `f0f77fe`，确认工作区干净后开始。

## 设计上下文

这是帮助用户登录问学桌面工具的产品界面。沿用现有 UIUX 与 PRD 的设计上下文：系统中文字体、白色内容面、黑色主按钮、中性灰辅助文字和单色线性图标。参考用户浅色截图的居中布局与留白；使用现有 token、16px 表单容器圆角和细边框，不新增远程字体或装饰阴影。设计资料保持在 `.project.agents/`，不另建技能默认的根级产品规范。

## 流程与文案

1. 恢复 `d7e2250` 的约 2.1 秒问字 Logo / slogan 开屏及表单入场；页面始终浅色，减少动态效果时直接显示表单。
2. 首页标题「欢迎回来」；线性账号图标配「使用账号密码登录」，分隔文字「或」、邮箱输入、黑色「使用邮箱继续」。按钮下保留中文隐私说明，仅「隐私协议」为链接，临时指向问学官网首页。
3. 邮箱验证码通过后，已有账号按原路径登录；新账号进入第一步「设置密码」，仅展示密码、确认密码与规则反馈。恢复逐字匹配着色及活动字符跟随，显示/隐藏开关互相独立。
4. 第一页「下一步」只校验密码，不建号。第二步「设置头像和昵称」提供可选头像与昵称；空白昵称最终自动填充 `user` 加六位数字，允许重复、不作为登录凭据。
5. 第二步「上一步」保留内存草稿，返回第一步修改密码；退出注册、切换邮箱、关闭或刷新仍丢弃全部验证凭据和资料。过期可重新验证。
6. 仅第二步「完成注册」调用现有注册句柄，沿用单飞、登录确认重试、头像保存重试与防重复建号。已建号后不能再返回修改密码草稿。
7. 登录、验证码、找回密码与两步注册共享浅色控件。步骤更替使用 180ms 淡入加 6px 位移，无弹跳；键盘焦点转到当前标题，减少动态效果时无位移。

## 验收

- 首页文案、单色图标、隐私链接与浅色模式可见；系统深色不改变页面。
- 两步注册按顺序显示；第一步不建号，第二步允许空昵称，返回保留草稿，退出清空草稿。
- 开屏播放与跳过、逐字匹配、密码遮蔽、验证过期、防双击、头像/登录确认重试均保持。
- 920×600 最小窗口和较大桌面窗口无裁切，窄窗口可滚动，Tab / Enter 可用。
- 定向测试、桌面 typecheck/build 与实际浏览器 UI 检查通过；模拟服务只用于 UI 验收，不冒充真实邮件或头像存储验收。
