# 首次使用分步操作动画

- 状态：用户已批准制作，2026-09-22；当前 Electron + CfT 运行时。
- 上游：`../../context/ARCHITECTURE.md` ConsoleUI、`../../context/UIUX.md` 桌面页、`../../refactor/ai-browser/01-product/PRD.md` 首次使用。

## 行为

登录后第一次进入且没有浏览器画像的账号展示六步实机操作动画：创建并命名、打开浏览器、打开网页、打开问学侧栏、发送任务、停止任务。素材必须来自当前产品实际操作录制，不能用绘制界面或虚构结果代替。观看不创建画像、不调用模型。以独立视频片段支持重播、暂停、上一步、下一步；每个步骤结束保持结果画面，点击下一步有淡出/位移/淡入衔接。最后一个分镜结束进入独立品牌页，复用 logo.png / slogan.png，以 Logo 展开和 slogan 显现动画收尾；只有点击「开始探索」才进入工作台，不自动创建实例。

全程提供「跳过教程」，直接回到工作台。完成和跳过按本机账号保存；已有画像的账号不自动打断，可从关于页重播。播放器不依赖网络，加载失败提供重试及跳过。尊重减少动态效果：不自动播放视频，保留手动播放；无大幅转场。关闭/退出前未完成不视为完成。切换账号不能复用上一账号的完成状态。

## 归属和边界

全部功能归属现有 ConsoleUI：OnboardingTour 内部视图、onboardingProgress 本机显示偏好。App 在认证和数据加载完成后呈现视图，完成/跳过只发出退出意图；无需新增 IPC、主进程服务或桌面控制插件通道。正式录制使用开发窗口与当前真实浏览器；素材版本和来源写入实施日志。已有未提交登录工作已在独立工作树基线保存，不改变原工作区。

## 验收

六个片段均可播放且目标可辨；前后步和重播可反复操作；最后片段结束出现品牌页；跳过和开始探索会退出并保存按账号的选择；关于页可重播；最小窗口 920×600、正常窗口、键盘和减少动态效果检查；素材播放错误可恢复；单元测试覆盖偏好隔离和迁移条件，类型/构建/浏览器视觉验证通过。无法获得真实 LLM 或跨平台录制证据时如实列为未完成，禁止伪造。

## 集成门禁（2026-09-22）

六段正式素材尚未就绪时，构建保留播放器实现和独立预览，工作台不自动进入教程且隐藏关于页重播入口；不会因素材缺失写入完成或跳过。构建包含全部六段指定 mp4 后启用正常引导。
