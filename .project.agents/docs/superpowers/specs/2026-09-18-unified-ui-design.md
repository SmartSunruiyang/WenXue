# 问学统一 UI 改造方案

## 授权与依据

用户确认 2026-09-18 浏览器画像页设计，并要求总结为问学 UI 指导、覆盖以前全部 UI 设计文档，再改造桌面端所有页面和插件设置、新标签页等页面。
唯一视觉规范为 [UIUX](../../context/UIUX.md)。当前工作区沿用此前直接同步授权；保留 CloudBase、网站等其他任务的在途改动。

## 范围与归属

沿现有 ConsoleUI、SidepanelApp、NewTabHome、Hub 与共享 client-operations UI 模块实施，不新增运行时模块或依赖，不改变数据 / IPC / Agent / 更新策略。

- 桌面：浏览器一致性、日志、Tokens、五类设置、登录 / 注册、空态 / 加载 / 错误与应用内消息更新。
- 插件：options 全设置及模型编辑，newtab 快捷入口 / 引导，Hub、sidepanel 与历史，共用控件与 token。
- 文档：重写 canonical UIUX；目标运行时 UIUX 引用其视觉正文并保留任务隔离等功能不变量；旧独立视觉稿 / prompt 转为入口或明确由统一规范替代，历史执行日志不改写。
- 网站 / 后台业务与发布不在本轮代码范围；共享中断组件的视觉一致应用到后台预览。

## 实施原则

白色内容、系统字体、黑色主按钮、轻灰交互、真实语义色；平面行、清晰标题和留白取代卡片套卡片。维持真实操作、自动保存、失败保留草稿、键盘和 reduced motion。
macOS 已批准的 72px 磨砂外壳和浏览器名称失焦保存必须保留。

## 验收

各表面提供对应类型 / lint / build / 相关既有测试证据；隔离 UI 预览覆盖正常、空态、错误、窄视口、弹层和关键交互。用 fixture 验证渲染与事件，真实账号 / CfT / LLM / 发布行为不得以 fixture 代证。
