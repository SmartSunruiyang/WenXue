# 手机短信登录与图形人机验证

- 状态：实施中；用户已授权先提交现有改动再开工，基线 `22ac96c`
- 归属：当前运行时 ConsoleUI / CloudBase Web Auth；沿用 UserSessionStore 与网关鉴权
- 上游：当前 ARCHITECTURE §2.1、§3.2；目标 PRD F10

## 行为

保留用户名密码登录和注册，新增手机号短信验证码登录。中国大陆手机号默认 +86；新号码通过 CloudBase OTP 创建账号，界面明确提示首次验证会创建账号。现有用户名账号应登录后从头像菜单绑定手机号，保持同一 uid；不得按昵称或手机号自动合并两个账号。已有绑定不在本次提供换绑或解绑。

发送验证码成功后开始 60 秒重发倒计时，校验 6 位验证码；修改号码废弃旧挑战与输入验证码，冷却时间保留。失败可重试，过期需重新发码。发送、验证期间禁止重复操作。关闭绑定弹窗或切换登录方式时销毁挑战；挑战不持久化、不进入日志。服务端仍负责实际频控、身份核验与禁用状态。

CloudBase 要求人机验证时显示真实图形挑战，由用户识别输入；成功后由 SDK 重试被保护的请求。错误答案、刷新、取消、过期均有反馈。12 秒网络超时不得误算用户阅读/输入图形验证码的等待时间。验证码不在前端自行判定正确。

短信登录产生的会话经现有主进程 setSession → 网关 activate 校验后才进入工作台。绑定前后验证当前 uid 一致，刷新用户资料和会话后同步主进程；绑定不自动切换账号，也不改变浏览器资料归属。

## 界面设计规范

- 目的：提供无需密码的登录方式，让原有用户在同一账号增加手机号凭据。
- 视觉：轻量工具式；复用已批准的平面表单、分段控件与原生模态，不新增装饰。
- 色板：既有背景白色 #FFFFFF、正文近黑 #0A0A0A、主按钮深灰 #171717、辅助灰 #666666；状态继续用 `--wx-signal-green` / `--wx-error-red`，实现引用现有语义变量。
- 字体：`system-ui, 'PingFang SC', 'Microsoft YaHei', sans-serif`，遵循 UIUX §4；项目设计系统优先于 UI skill 的通用字体/居中布局限制。
- 布局：原登录居中限宽区域；登录方式就地切换，短信表单字段纵排，验证码与发送按钮同一行；绑定在头像菜单打开原生 dialog，保留焦点圈定、Escape 与关闭后的焦点恢复。
- 可访问性：显式标签、错误 alert、发码状态提示、键盘提交、禁用与加载状态；手机掩码展示，不显示认证令牌。

## 验证

服务测试覆盖手机号/验证码校验、发送失败、挑战过期/一次性使用、手机号绑定 uid 一致性、账号禁用由现有激活边界拒绝、验证码取消与重试、超时和不泄露凭据。运行桌面类型检查、相关测试、构建、lint/格式检查；隔离本机预览验证表单、模式切换、倒计时、绑定弹窗及图形验证交互。真实短信收取和完整账号绑定需要用户实际号码与验证码参与，不以 fixture 声称真环境验收。
