# macOS 桌面玻璃外壳

> 2026-09-18 视觉规范更新：本文的功能 / 运行时契约继续有效；所有颜色、排版、布局、动效和组件样式以 [统一 UIUX](../../context/UIUX.md) 为准，旧视觉示例仅为历史。

## 已确认的目标

用户确认仅升级 macOS 主窗口外壳，浏览器、日志、Tokens、设置共用。保留页面内部布局与功能，
设置的次级分类栏与正文一起位于一张内容卡片内。本次固定浅色，不做深色主题。

视觉参考为用户提供的微信 macOS 截图：系统红绿灯完整位于左侧导航内，左栏和露出的窄底板
使用系统磨砂材质，内容区以圆角覆盖底板，取代从顶到底的直线分隔。

- 当前 Electron 运行时：`../../context/ARCHITECTURE.md` §2.1 ConsoleUI / MainBootstrap。
- 视觉身份、工具型产品定位、字体与可访问性沿用 `../../context/UIUX.md`，不另建重复产品文档。

## 设计与实现

- 按用户后续反馈，macOS 导航栏由 96 px 收窄至 72 px；系统红绿灯起点 `(10, 20)`，保留原生尺寸和点击区域。
- Electron 原生 `vibrancy: under-window` 提供磨砂底板，`visualEffectState: active` 在失焦时也保留背景采样；原生外观固定 light。
  不引入 macOS 26 专属桥接或升级 Electron，继续使用现有版本支持的系统材质。
- renderer 底板和左栏背景完全透明，去掉浅色覆层，让窗口后的背景经系统模糊后透出；保留系统“减少透明度”行为，不使用伪造红绿灯或整窗 `transparent` 模式。
- 主内容从导航栏右侧开始，顶/右/底外边距 8 px、圆角 16 px、不透明浅色表面，细轮廓和短阴影。
- 移除 macOS 左栏贯穿分割线；次级栏留在主内容内。页头保留拖动安全区，内容、导航、输入和菜单
  仍可点击；设置菜单、账号菜单、提示、弹窗不被新卡片裁切。
- Windows / Linux 的原有宽度、平直结构与自绘窗口控制保持原规则；登录入口维持现有布局。

## 验收

- macOS 1120×720 与最小 920×600 下，红绿灯不跨出导航、不与头像重叠，圆角四周可见。
- 四个主路由及设置次级栏使用一致外壳；滚动、导航、菜单、焦点与拖动安全区正常。
- 原生磨砂真实可见，浅色内容不随系统深色切换。无新增循环动画。
- 更新现有窗口选项单测，完成桌面类型检查、构建、相关单测与 Electron 视觉检查。
- 原工作区现有 CloudBase 修复保留；首版在 `codex/macos-glass-shell` 独立工作区实施，用户已要求直接同步，后续细化在原工作区继续。
