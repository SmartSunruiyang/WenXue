# 给 UI 设计 AI 的 Prompt — 问学 WenXue 启动器（App 化 / 白色 / 多开）

> 用法：把下面「===== PROMPT 开始 =====」到「===== PROMPT 结束 =====」之间的全部内容，整段复制给 UI 设计 AI（如 v0 / Figma AI / Claude 等）。配套功能需求见 [同目录 design 文档](./2026-06-26-launcher-app-redesign-design.md)。

===== PROMPT 开始 =====

## 你的角色

你是一名资深产品 UI/UX 设计师。请为一款 **Electron 桌面应用**「问学 WenXue 启动器」设计**高保真界面**。这是一个浏览器多开管理工作台：用户在这里添加、命名、并同时启动多个隔离的浏览器实例，查看插件运行日志，并配置启动默认值。请交付干净、专业、像成熟桌面 App 的设计（参考气质：Linear / Arc / Raycast 的克制与精致），**不要**做花哨堆砌。

## 产品语境

- 品牌：中文「问学」，英文「WenXue」，副标题 slogan「ask for everything」（小写排印）。
- 品牌气质：**克制、学术、工具感** —— 像一件趁手的研究工具，不拟人、不卖萌、不堆装饰。
- 这是给一个"内置 Chrome 浏览器 + 注入 AI 网页操作插件"的桌面套件做的**启动器**。用户的核心动作：管理多个浏览器画像、一键多开、看日志、调设置。

## 硬约束（必须遵守）

1. **白色单一主题**：只设计**浅色 / 白色**界面。**不要**设计深色模式，**不要**做明暗适配，**不要**用 `prefers-color-scheme`。整套只有一个白色主题。
2. **无系统标题栏（无边框窗口）**：窗口没有传统标题栏。但要为系统窗口控件**留出安全区**：
   - **macOS**：**左上角**有悬浮的红/黄/绿三个圆形系统按钮（关闭/最小化/缩放）——左上角约 80×28px 区域不要放可点元素。
   - **Windows**：**右上角**有原生的最小化/最大化/关闭三键浮层——右上角约 138×32px 区域不要放可点元素。
   - 顶部留白区作为窗口拖拽区。请把布局设计成"左上、右上各让出一块系统控件安全区"也能成立。
3. **常驻窄图标侧边栏**：左侧有一条**始终存在**的窄图标导航栏（宽约 64–72px），任何页面都不隐藏。
4. **App 化窗口尺寸**：按桌面应用比例设计，默认画布约 **1120×720**（也给出窗口更宽时的自适应表现）。不要按手机或小弹窗设计。
5. **像素级专业度**：对齐、间距、层级、空状态、hover/active/禁用态都要交代清楚。

## 配色 Token（精确值，请直接使用，源自产品现有品牌系统）

> 颜色用 `oklch`。这是品牌既有调色板，请严格采用；**能量强调色只用于状态与点缀**，不要铺底、不要做大面积彩色背景。

**中性 / 底色 / 文字**

- 背景（页面）：`oklch(0.985 0 0)`（近白）
- 背景（更深区/分隔）：`oklch(0.92 0 0)`
- 前景（主文字）：`oklch(0.12 0 0)`（近黑）
- 次要文字：`oklch(0.44 0 0)`；更弱：`oklch(0.58 0 0)`

**面板 / 玻璃 / 描边**

- 面板白（半透玻璃）：`oklch(1 0 0 / 0.78)`；更实：`oklch(1 0 0 / 0.9)`
- 玻璃高光线：`oklch(1 0 0 / 0.65)`
- 边框：`oklch(0.82 0 0 / 0.7)`；强边框：`oklch(0.12 0 0 / 0.16)`

**能量强调色（仅状态 / 点缀 / 主按钮微光）**

- 电蓝 `oklch(0.72 0.18 245)` · 激光紫 `oklch(0.72 0.22 305)` · 量子青 `oklch(0.78 0.18 185)` · 信号绿 `oklch(0.74 0.17 150)` · 珊瑚 `oklch(0.76 0.18 35)` · 错误红 `oklch(0.64 0.24 25)`

**主操作按钮**

- 底：`oklch(0.12 0 0)`（近黑）/ 字：`oklch(0.98 0 0)`（白）

**状态语义**：空闲=中性灰 · 启动中=珊瑚 · 运行中=信号绿 · 异常=错误红。状态**不能只靠颜色**，要配文字标签 + 状态点。

## 排版 / 图标 / 形状

- 字体：`system-ui, 'PingFang SC', 'Microsoft YaHei'`；**版本号、日志、时间戳用等宽** `ui-monospace`。
- 层级：标题 16–18px/600，正文 14px/400，辅助 12–13px/次要色；中文正文不小于 13px。
- 图标：统一用 **Lucide** 线性图标。
- 圆角：12–18px（卡片/面板/按钮）；输入与小控件 8–12px。
- 间距：4px 基数刻度（8 / 12 / 16 / 24 / 32）。
- 质感：干净白底 + 极淡边框 + 克制阴影；可用**很轻**的玻璃模糊点缀面板，但整体是"干净白色 App"，不是炫光控制台。

## 需要设计的界面（逐屏）

### A. App 外壳 + 侧边栏（所有页面共享）

- 无边框窗口；左上/右上系统控件安全区按上文留白。
- 左侧窄图标栏，自上而下：
  1. **头像**（顶部，在 mac 红绿灯安全区**之下**）——圆形，默认是带首字母的品牌色块。
  2. **Chrome 图标**——进入「浏览器」页（默认页）。
  3. **日志图标**——进入「日志」页。
  4. **Tokens 图标**——进入「Tokens」统计页，查看本机模型调用消耗。
  5. 弹性空白。
  6. **设置图标**（底部）——进入「设置」页。
- 给出图标的**默认 / hover / 激活**三态（激活态建议：左侧细高亮条 + 轻底色 + 图标变主色）；hover 出 Tooltip。

### B. 浏览器页（默认页，多开核心）

- 顶部：页标题「浏览器」+ 右侧「**添加浏览器**」主按钮（近黑底白字）+（可选）搜索框/排序。
  - ⚠️ 注意：Windows 在**右上角**有系统三键浮层（见硬约束 2）。此处右对齐的操作要为其**预留右内边距（≈138px）**、不要顶到窗口最右边，否则会被系统按钮压住。
- 主体：**浏览器列表**，每行一项，含：
  - 左侧**多选复选框**
  - 首字母**色块/头像**（用能量色派生）
  - **展示名**（支持就地重命名——给出"双击进入编辑态"的样子：行内输入框 + 保存/取消）
  - **状态点 + 文字**（空闲灰 / 启动中珊瑚 / 运行中绿 / 异常红）
  - **上次使用时间**（等宽、相对时间）
  - 行尾**操作**（hover 显示）：打开、聚焦/停止（运行中）、重命名、复制、删除、打开文件夹
- **多选态**：勾选若干行后，**底部浮出操作条**：「打开选中 (N)」主按钮 +「取消选择」。
- **运行中的行**：可加**一道很轻的品牌运行态描边/光晕**（低饱和、克制），表示"正在运行"，但不要盖过内容。
- **空状态**：无浏览器时，居中品牌空态——「问」字 logo（克制呼吸感）+ slogan + 「添加第一个浏览器」主按钮。
- 请给出：默认列表态、含运行中/启动中/异常混合状态、多选+底部操作条、就地重命名、空状态，共 ~5 个画面。

### C. 日志页

- 用途：实时查看浏览器内 AI 插件的操作日志，永久保存，可删除/导出。
- 顶部工具条：「跟随最新/暂停」开关、**筛选**（级别多选 debug/info/warn/error、来源多选 agent/llm/tabs/page/chaoxing/config/system、**按浏览器/画像** 多选、时间范围）、**全文搜索**、「清空」、「导出」（JSON / NDJSON / 纯文本）。
  - ⚠️ 同样为 Windows 右上系统三键浮层预留右内边距：把「清空 / 导出」等右对齐操作收在安全区左侧，不要顶到窗口最右边。
- 主体：**等宽日志流**，每行：时间戳（等宽）+ 级别色标 + 来源标签 + 浏览器标签（多开归类，用色点区分）+ 消息。支持点击**展开单条详情**（JSON 折叠/展开，框内滚动不撑宽）。虚拟滚动承载海量条目。
- 顶部给一个级别/来源**图例**（色 + 文字，不只靠颜色）。
- 请给出：日志流默认态、展开某条详情态、筛选打开态，共 ~3 个画面。

### D. 设置页

- 左侧分类 + 右侧内容；**改动即时保存**（无保存按钮，保存后顶部短暂「已保存」反馈）。
- 分类与项：
  1. **启动默认值**：默认窗口尺寸/位置、起始页 URL、同时打开上限、错峰间隔、新建画像默认类型（持久/无痕）、代理、界面语言、默认缩放。
  2. **启动器行为**：关闭按钮行为（最小化到托盘/退出）、退出时浏览器在运行的处理（询问/仅退出启动器/一并关闭）、开机自启、默认下载目录。
  3. **日志**：保留时长、最大条数、最低捕获级别、是否捕获 LLM 请求/响应、默认导出格式。
  4. **浏览器内核**：CfT 版本（只读）+ 重新拉取/修复、打开画像根目录。
  5. **关于**：App/内核/插件 三元版本号（等宽）、打开日志目录、外部链接。
- 控件：自绘的开关、下拉、数字输入、文本框（不用浏览器原生 `<select>` 的默认样式）。给出 1–2 个分类的完整画面。

### E. Tokens 统计页

- 用途：查看本机 tokens 消耗趋势、模型分布与浏览器画像归因。
- 顶部：总输入 tokens、总输出 tokens、总 tokens、估算人民币成本四个摘要块。
- 主体：按浏览器画像 / 模型 / 日期聚合的轻量图表或条形列表；右侧或下方展示最近调用明细。
- 空状态：无数据时说明统计来自已脱敏日志遥测或后续网关计量，不保存提示词正文、API Key 或敏感头。

### F. 头像菜单（Popover）

- 点击侧栏顶部头像弹出的轻量菜单：资料（展示名 + 换头像/色块）、设置、关于、退出。给出 1 个画面。

### G.（可选）退出确认对话框

- 浏览器仍在运行时关闭 App 的确认弹窗：标题「浏览器仍在运行」+ 一句话 + 「仅退出启动器」（默认）/「一并关闭浏览器」。

## 交互与状态要求

- 给全每个可交互元素的 **default / hover / active / focus / disabled** 态；焦点态用可见的 ring（无障碍）。
- 主按钮 hover 可有**很轻**的横向微光（用能量色），但不要循环动效轰炸。
- 列表项 hover 浮起操作；多选时复选框与底部操作条联动。
- 尊重"减少动态效果"：所有动效都要能退化为静态。

## Do / Don't

**Do**：干净白底、清晰层级、克制留白、统一 Lucide 图标、能量色只点状态、等宽用于日志/版本/时间、像成熟桌面 App。
**Don't**：不要深色模式；不要大面积彩色/渐变铺底；不要把"能量玻璃光效"做成页面主视觉；不要传统标题栏；不要遮住系统控件安全区；不要用拟人吉祥物或表情符号装饰；不要把它设计成手机 App 或网页落地页。

## 交付物

- 高保真桌面界面（浅色，画布约 1120×720，并示意更宽时的自适应）。
- 覆盖上面 A–F（G 可选）全部关键画面与状态，约 12–15 张。
- 标注关键间距 / 字号 / 颜色 token 用法。
- 一份简短的组件清单（侧栏图标项、浏览器行、状态点、多选操作条、日志行、筛选条、设置控件、头像菜单）。
