# 浏览器画像页 UI 与交互重设

> 2026-09-18 视觉规范更新：本文的功能 / 运行时契约继续有效；所有颜色、排版、布局、动效和组件样式以 [统一 UIUX](../../context/UIUX.md) 为准，旧视觉示例仅为历史。

## 本轮依据

用户要求重新设计桌面端浏览器画像页，明确不沿用以前的风格要求，仅参考问学插件页面与 OpenAI 设计。
视觉依据为插件 `assets/index.css` 的中性 token、`components/ui/button.tsx` 的轻量按钮和侧栏交互，
以及 [OpenAI UI guidelines](https://developers.openai.com/plugins/concepts/ui-guidelines) 中的字体、层级、间距与单色图标原则。
保留问学品牌。现有 macOS 外壳属于上一轮已完成成果，本次仅重设内容页。

## 模块与边界

属于 `../../context/ARCHITECTURE.md` 中已有 ConsoleUI，更新 `../../context/UIUX.md` 的浏览器页规范。
沿用现有 typed IPC 和画像生命周期；不改后端服务、账号隔离、持久化、窗口材质和其他页面。
浏览器页的新文案进入现有 `strings.ts`。

## 设计

- 明确的页头、单一“新建浏览器”主操作；纯白背景、系统字体、黑白灰控件，颜色仅作为画像识别和状态提示。
- 搜索、原生排序选择器与批量选择独立成工具栏；下方为带真实数量的状态筛选。
- 列表无外框和灰色表头；名称优先，最近使用作为次级信息，不在常态逐行展示技术 ID。
- 画像标记用浅灰底与小面积识别色，运行状态不再铺满整行；主操作为打开 / 打开窗口 / 重试。
- 批量模式才显示复选框，支持当前结果全选和半选状态，底部操作区保留真实选中数量；执行时锁定相关交互。
- 已选画像在状态变化时继续出现在当前结果中，避免启动失败后选中项被筛选隐藏、无法重试。搜索或状态筛选变化清空选择。
- 新建、复制清空筛选并进入行内命名；焦点离开编辑区自动保存，取消按钮与 Escape 放弃修改，失败保留草稿，异步保存不打断随后新建的命名；更多菜单保留重命名、复制、目录、删除及异常日志入口和键盘操作。
- 空画像与筛选无结果采用不同说明与动作；清除搜索、重置筛选均可直接操作。
- 1120×720 和 920×600 可用；列表独立滚动，页头、筛选及批量操作保持可达；支持长名称、错误、启动中、禁用与减少动态效果。

## 验收

构建、类型与 lint 检查；隔离 Electron UI 检查正常列表、筛选、排序、全选/半选、批量、行内命名、更多菜单、空状态、长名称和最小尺寸。
UI 数据使用隔离 fixture，不触碰真实账号和浏览器；不声称 fixture 可证明 CfT 启动链路。
