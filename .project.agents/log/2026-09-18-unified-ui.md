# 2026-09-18 问学跨端 UI 统一

## 用户授权与目标

用户认可浏览器画像页的新设计，明确要求将其总结为后续问学 UI 指导、覆盖现有 UI 设计文档，并推广到全部桌面页面与插件设置、新标签页等界面。延续此前直接同步、浅色优先的授权；本次在原工作区实施，保留已有原生外壳、画像失焦自动保存及其他并行改动。

设计与计划：

- [统一 UIUX](../docs/context/UIUX.md)
- [本轮设计](../docs/superpowers/specs/2026-09-18-unified-ui-design.md)
- [实施计划](../docs/superpowers/plans/2026-09-18-unified-ui.md)

## 设计收敛

内容优先，白底与中性黑灰，系统字体，通过留白和文字层级组织信息。40px 主控件、黑色主操作、平面列表与克制分隔；仅使用有意义的状态色和 150–200ms 反馈。保留已批准的 macOS 原生磨砂外壳与不透明内容卡片，不将玻璃、粒子、漂浮 Logo 或整页编排推广到内容页。

统一 UIUX 为唯一跨端视觉正文。旧启动器提示词、重设计稿、新标签页视觉计划收敛为规范入口；账号、模型、公告、续接、启动链与目标 Chromium 文档保留功能约束，移除冲突的视觉要求和“视觉另行设计”占位。历史执行日志、第三方引用资料不改写。
