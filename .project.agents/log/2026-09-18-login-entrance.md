# 登录页问字与 slogan 入场动效

- 日期：2026-09-18
- 归属：当前运行时 ConsoleUI
- 计划：[登录页品牌入场动效](../docs/superpowers/plans/2026-09-18-login-entrance.md)

## 做了什么

- 在现有 `AuthScreen` 增加入场 UI 状态：问字居中浮现，品牌组合左移并向右展开现有 slogan 图片，短暂停留后淡出，随后浮现欢迎语与登录表单。
- 表单顶部移除常驻品牌区，保留原有标题、说明、登录 / 注册切换、字段、错误和提交控件设计及认证逻辑。
- 动画只在进入未登录页面时播放；字段输入、校验、模式和窗口状态更新不重播。入场期间不挂载表单，结束后恢复用户名自动聚焦。
- 系统减少动态效果偏好开启时直接显示表单；播放中偏好变化可以立即结束入场，计时器和监听随卸载清理。
- 动画使用 transform / opacity 和局部裁切，未引入依赖、资产、IPC 或存储变更。同步 UIUX §2、§6、§7 的登录页特例；没有架构边界变化。
