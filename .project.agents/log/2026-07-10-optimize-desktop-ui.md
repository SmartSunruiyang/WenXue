## 做了什么

- 将浏览器页从“指标卡 + 行卡片 + 重复检查器”收敛为状态摘要与单一画像列表；主操作保留在行内，重命名、复制、目录与删除归入更多菜单，异常画像提供重试与查看日志。
- 更多菜单提升到页面顶层，避免末行和窄窗裁切；补齐方向键、Home / End、Tab、Escape、外点关闭与焦点回位，账号菜单同步补齐键盘模型。
- 修复搜索无结果误报、隐藏选择参与批量启动、批量启动异常悬挂、登录重复提交、Tokens 空态假按钮、日志跟随不滚动、日志筛选空态误报、头像菜单关于入口错误等交互问题；批量启动只清成功项，失败画像保留选择供重试。
- 未登录时无条件加载真实窗口信息，Windows / Linux 登录页可显示自绘窗口三键；窗口、画像、日志、设置与退出登录动作补齐失败反馈。
- 设置页只保留已有真实消费者的可交互字段；未来能力改为规划说明。数字项增加范围 / 步长校验、保存中互斥、失败回退与串行自动保存，并显示“自动保存 / 正在保存 / 已保存”状态。
- Tokens 收敛为总览条、两个分布面板、全宽日期趋势和最近调用表格；版本信息改为无嵌套卡片的定义行。
- 提升焦点环、控件边界、辅助文字、状态色与画像色块对比度；补齐 `aria-current`、`aria-pressed`、`aria-expanded`、错误 live region、控件可访问名称和减少动态效果兼容。窄窗保留逐行状态文案并隐藏长 ID，不产生横向溢出。
- 登录 / 工作区数据加载、画像动作、批量启动、日志清理、Tokens 刷新、设置保存与退出登录增加请求代次和互斥，避免跨账号回写、晚到响应复活旧状态或重复提交。
- 同步 `UIUX.md` 桌面主窗口与可访问性规范，并把新增错误文案集中到 `strings.ts`。
