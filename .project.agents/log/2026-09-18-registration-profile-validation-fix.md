# 注册后账号资料核验修复

- 关联提交：`1ec0b33 fix(desktop): 修复短信登录与手机号验证注册流程`；本轮提交 `fix(desktop): 修复注册资料校验与登录交接`，代码、架构说明和此日志同一提交。
- 复现与定位：手机号验证注册或旧短信账号补全后，客户端提示“账号资料无法确认，请稍后重试或重新登录”，没有交接登录会话。嫌疑模块为当前运行时 `ConsoleUI/cloudbase.ts`，跨越 CloudBase Web Auth SDK 用户资料与桌面会话交接契约。已安装 SDK 将用户名放在 `user_metadata.username`，此前注册分支读取顶层 `username`；旧账号补全分支在成功更新后额外 `refreshUser()`，且再次读取不存在的顶层用户名，因此成功更新也会被误判失败。
- 修复：新注册和旧账号补全统一从 SDK 用户资料的 `user_metadata.username` 读取用户名；补全注册使用 `updateUser()` 返回资料校验 uid、手机号与用户名，再交给网关校验会话。对已补全的旧账号提示返回登录，避免重复发送注册短信。保留网关激活和 uid 检查。
- 验证：桌面认证及主进程会话 104 项用例通过，包括真实 SDK 字段结构、资料更新后刷新失败、错误 uid 和已完成账号；类型检查、相关 ESLint、Electron Vite 构建通过。未使用真实手机号或短信验证线上 CloudBase 环境，实际发码与网关账号状态仍需现场验收。
- 下一步：在真实 CloudBase 环境用测试账号走新号注册、旧账号补全与短信/密码重新登录；若激活仍失败，记录脱敏的网关状态码与错误码以区分云端账号状态和客户端解析问题。
