# 侧边栏新增新建对话按钮

- **日期**：2026-06-13
- **关联**：PRD F3 侧边栏对话 / UIUX §6 侧边栏 / 模块 SidepanelApp (L5)
- **会话上下文**：用户要求“插件主页右上角增加一个小加号按钮，用来创建新对话，点击加号后现有的聊天记录要有删除的动画效果”。开工前按用户要求先提交既有脏区。

## 做了什么

- 侧边栏聊天主页右上角新增小加号按钮，位置在历史按钮与更多菜单之前；按钮有中英文 `aria-label` / `title`。
- 点击加号时，当前可见对话流先播放短暂淡出、下滑、缩小的删除动画，再清空 `currentTask`、`history`、`activity` 并回到空态，同时把焦点放回输入框。
- 运行中任务禁用新建对话按钮，避免底层 Agent 仍在运行时开启新任务；用户仍可先使用停止按钮。
- 在 `useAgent` 增加可测的对话状态 helper 与 `resetConversation`，并新增单测覆盖“有可见对话内容”和“清空后状态”。
- 同步更新 PRD F3 与 UIUX §6，明确新建对话按钮、删除动画、运行中禁用与历史记录不受影响。
