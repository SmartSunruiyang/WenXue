# 浏览器名称失焦自动保存

## 请求与变更

用户要求新建浏览器进入名称编辑后，点击页面其他位置时自动保存，等同点击对号。
在现有 ConsoleUI 的名称编辑区处理焦点离开，复用 commitRename 与 typed IPC。编辑区内部移动焦点不提交；对号和 Enter 保存，取消按钮和 Escape 放弃修改。

保存成功仅关闭本次画像的编辑状态，避免用户连续新建时，先前保存的异步返回关闭新的名称输入框或清空新草稿。空名称校验及失败提示沿用原有逻辑。
同步 UIUX 与既有浏览器页设计文档；未改变模块边界、样式或依赖，未修改其他在途变更。

## 验证

- renderer TypeScript、App.tsx ESLint、生产 electron-vite build、相关 Prettier 与 `git diff --check` 通过。
- 在隔离 Electron 预览中使用临时画像、1 秒延迟和可控失败 fixture，实际验证点击页头自动保存、对号保存、Enter 保存、取消按钮、Escape、连续新建、空名称校验、失败后保留草稿并重试。
- 通过 fixture 的调用计数确认：三种保存入口各只发送一次；取消、Escape 与空名称没有发送重命名请求。
- 连续新建时旧名称成功保存，新输入框和新草稿仍保留。失败后输入内容未丢失，修正后可成功保存。
- 验证未访问真实账号或画像数据；隔离预览已关闭。
