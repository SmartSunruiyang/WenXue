# 固定登录页纵向比例并还原参考图细节

- 日期：2026-09-22
- 关联：ConsoleUI、UIUX §7、[浅色认证设计](../docs/superpowers/specs/2026-09-22-auth-light-ui-design.md)。
- 会话上下文：用户对上一轮待审阅的浅色登录页提出视觉修订；本次在该版本上继续调整，保留既有认证流程改动。

## 做了什么

- 复现高度断点问题：1120×900 / 720 / 600 时，卡片高度分别为 305.9 / 281.9 / 273.9px，标题下间距分别为 40 / 24 / 20px。
- 移除认证区 740px / 640px 的高度断点，固定标题与表单间距、内边距、输入框和按钮尺寸。整体随窗口保持居中，空间不足时滚动。
- 根据用户原图的二倍像素比例，采用 32px 标题、64px 标题间距、448px 外框、28px 内边距、32px 外圆角，以及 40px 高 / 16px 字体 / 10px 圆角的控件。
- 从原图取样认证背景 `#fcfcfb`、控件内底 `#fefefd`、外框边缘 `#e4e4e3`、控件边缘 `#e6e6e5` 和主按钮 `#0b0b0b`；增加低透明度柔光与辅助按钮轻阴影。
- 同步密码比较层字号及显示按钮垂直对齐，窄窗口仅调整横向留白。
- 更新统一 UIUX 与既有派生设计、计划；未改变模块、依赖、认证行为或产品流程。
