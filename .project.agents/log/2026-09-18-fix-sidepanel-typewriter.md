## 原因与修复

- 上次恢复了打字机 hook，但未验证输入框最终呈现的动态文字。普通任务传入的 `placeholder: undefined` 在 props 展开时覆盖了动态 placeholder，导致空输入框始终无提示。
- `TaskInput` 先展开属性，再按显式提示优先、动态提示兜底设置 placeholder。存在明确的问题回答提示时，暂停不可见的打字机定时器。
- 继续保留逐字输入 / 停留 / 删除 / 下一句循环、聚焦或已有内容时暂停、空值失焦后恢复、减少动态效果时显示静态完整提示。
- 本次没有新增视觉或交互规则，沿用 [UIUX §10](../docs/context/UIUX.md#10-侧边栏对话与历史)。设置网页及其他页面不变。
