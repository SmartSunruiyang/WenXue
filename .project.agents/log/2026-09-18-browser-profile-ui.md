# 浏览器画像页 UI 与交互重设

## 请求与范围

用户明确要求浏览器画像页不沿用以前的风格要求，仅参考问学插件页面和 OpenAI 的设计。
按既有“直接同步”授权在当前工作区落地，范围为现有 ConsoleUI；保留上一轮 macOS 外壳。
本轮不新增依赖、IPC、持久化或后端能力。

视觉依据为插件的中性 token、按钮及侧栏源码，和 [OpenAI UI guidelines](https://developers.openai.com/plugins/concepts/ui-guidelines) 的系统字体、层级、间距与单色图标原则。
使用 impeccable 技能辅助设计，按用户本轮指示替代本页旧审美约束。

## 变更

- 白色内容、黑色主操作、中性灰层级，独立页头与工具栏；宽松的列表行和内缩细分隔线，名称优先，最近使用作为辅助信息。
- 新增带真实数量的状态筛选；保留名称、ID、目录搜索和最近使用 / 名称 / 状态排序。清除搜索后焦点回到搜索框。
- 批量选择按需展开，支持当前结果全选与半选；列表独立滚动，底部操作区保持可见。执行期间禁用相关控件，选中勾选不闪退。
- 已选项在启动期间和失败后保持可见，解决当前状态筛选可能隐藏失败项、导致无法重试的问题。
- 新建与复制会清除筛选并进入行内命名；支持 Enter 保存、Escape 取消，输入法组词中的 Enter 不触发保存。
- 更多菜单保留重命名、复制、目录、删除与异常日志入口，支持方向键及 Escape 焦点恢复，底部空间不足时向上展开。
- 区分初次使用空页面和搜索无结果；新文案集中到 strings.ts。
- 页面样式独立为 BrowserPage.css，在 main.tsx 引入，并从 index.css 清理被替代的浏览器样式。更新 UIUX、设计及实施计划。
