# 桌面账号资料与弹层交互优化

- 日期：2026-09-22
- 范围：用户要求的头像同步、设置「我的」、二级菜单动效、自绘询问与下拉、箭头留白、柔和焦点效果。
- 模块：当前 Electron + Chrome for Testing 运行时的 ConsoleUI、DesktopBridge、MainBootstrap；未增加业务模块或运行依赖。

## 完成内容

- 注册预览、首页、账号菜单与「我的」使用同一账号头像及 12px 圆角方形；CloudBase Auth 保存永久文件引用，展示解析的临时 URL。
- 「我的」支持昵称与头像编辑、完整只读 UID 与邮箱、复制 UID、安全退出；提交期间禁用重复操作，失败保留草稿。服务验证昵称、图片类型与大小、写入结果和异步阶段 UID。
- 保存后同步各处公开资料。修复保存期间清日志导致资料回包被丢弃，以及较旧会话刷新回包覆盖最新资料的并发边界。
- 头像菜单、浏览器操作菜单、排序和设置选择器复用自绘弹层，支持实际尺寸定位、窗口边缘翻转、键盘导航、外部点击和焦点恢复。展开使用约 160ms 淡入与轻微位移；箭头右侧留 14px。
- 删除、清空日志、退出登录、关闭窗口询问/失败提示均自绘。验证码弹窗使用相同容器。顶层弹窗隔离背景公告/更新弹窗的 Escape、Tab 处理，内部选择器仍优先处理键盘。
- 关闭窗口通过类型化 IPC 请求与应答保留主进程退出决策，验证发送方与请求 ID；重复请求合并，renderer 失效时取消关闭，关闭浏览器失败保留窗口。
- 输入框与交互控件改用低强度柔光；组合搜索框只在外层显示光晕。保留减少动态效果与强制颜色模式支持。
- 同步 ARCHITECTURE、UIUX、目标 PRD 和实施计划。
