# 完成浅色登录与先密码、后资料的两步注册

- 日期：2026-09-22
- 关联：[设计](../docs/superpowers/specs/2026-09-22-auth-light-ui-design.md)、[实施计划](../docs/superpowers/plans/2026-09-22-auth-light-ui.md)、UIUX §7、PRD F10、ARCHITECTURE ConsoleUI。

## 做了什么

- 先按用户要求提交上一轮邮箱认证、网关与管理后台改动，确认工作区干净后开始本次工作。
- 登录改用既有浅色语义 token；首页「欢迎回来」，账号密码入口配单色图标，黑色邮箱继续按钮下保留中文隐私说明。「隐私协议」链接与插件关于页相同的官网首页，通过现有 DesktopBridge HTTPS 外链能力打开。
- 从 `d7e2250` 恢复 Logo/slogan 品牌开屏及表单入场、密码逐字匹配动画和活动字符跟随；默认遮蔽密码，两个显示按钮独立，支持减少动态效果。
- 注册拆为密码与确认、头像与昵称两步。前一步只校验，最终提交才创建账号；返回上一步保留内存草稿，返回邮箱入口清理挑战及草稿。保持过期、单飞、登录确认重试和头像重试语义。
- 认证适配层在最终调用建号接口时为空白昵称生成 `user` 加六位数字；名字仅展示，不承诺唯一编号，重试不改名、不重复建号。未改变 SDK、云端配置或部署。
- 步骤切换采用 180ms 淡入与 6px 位移；920×600 下密码页主操作完整可见，窄窗口无横向溢出。
- 两个实现子任务分别完成注册默认名称/服务测试，以及界面行为测试；主任务整合组件、视觉样式、文案、文档与浏览器验收。
