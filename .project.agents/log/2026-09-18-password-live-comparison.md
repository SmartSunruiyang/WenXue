- 日期：2026-09-18

## 做了什么

- 密码提示拆为长度、首位字符、允许字符、至少三类字符四个独立条件，空值灰色、满足绿色、不满足红色；与用户名共用带状态图标、读屏状态文字的提示呈现。
- 提取密码条件结果供界面和提交校验共用，保留错误优先级；允许字符判断明确拒绝末尾换行。
- 二次确认按字符位置比较，首次密码对应位置出现约 180ms 浮现的绿色或红色底板；未输入的位置无底板，错误位置不阻断后续位置独立判断。修改、粘贴、删除任一输入即时重算。
- 上方输入非编辑态采用不可交互的字符覆盖层，隐藏时只呈现圆点，显示时呈现字符；编辑上方输入恢复原生输入，以保留光标、选择及自动填充行为。覆盖层不进入可访问树，不记录密码。
- 长密码对照层跟随当前确认位置滚动；显示按钮可独立使用。确认框下方给出匹配进度、首个不一致位置、额外字符数或完全一致文字，颜色不作为唯一反馈。
- 底板支持减少动态效果的 CSS 分支；同步 UIUX 和现有实施计划，无模块、依赖或认证接口变更。
