## 做了什么

- 官网使用桌面内容区同一纯白 `#ffffff`、系统字体与中性控件；首页主标题为「Agent，直接操作浏览器」。保留真实演示录屏，改为由用户播放的原生视频控件，移除粒子、标题入场及悬浮变形。
- 顶部文档右侧新增隐私，桌面与手机入口一致，页脚提供两份政策直达链接；手机菜单支持 Escape 回焦与外部点击关闭。
- 文档重新组织为 7 篇使用指南，保留旧文章链接，加入全文搜索、无结果与清空、三栏布局、手机折叠导航、页内目录与前后篇跳转。移除旧截图占位和过时的数据流 / 自动提交保证。
- 新增隐私协议 10 节、用户须知 8 节。用户确认主体 `Askwenxue.com opc`、联系邮箱 `contact@askwenxue.com`；参考 OpenAI 政策结构，按当前产品数据流独立撰写。
- 明确内置模型经 CloudBase / 百炼、自定义模型直连、本地浏览器资料、云端账号 / 用量、日志与更新事件的区别。当前上海网关、更新事件保留 30 天依据 TECH-INFRA；其他未知规则保留草案说明。
- 路由保留静态站兼容的 hash 形式：`#docs/<article>`、`#privacy/privacy-policy`、`#privacy/terms-of-use`；政策章节支持第三段锚点。修复重复点击同一复合 hash 不再定位的问题。
- 用户确认暂无下载链接；下载区显示「下载入口准备中」及使用指南入口，不链接公开访问返回 404 的 Releases 页面。
