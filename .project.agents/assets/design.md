# 问学 WenXue 设计语言规范

> 本文只定义问学 UI 的视觉语言：颜色、字体、材质、特效、动效和资产使用。它用于指导启动器与 extension 保持同一套高能视觉系统。

## 1. 视觉方向

问学的视觉不走“克制工具感”，而是走 **高能 AI 浏览器驾驶舱**：

- 关键词：炫酷、智能、玻璃、流光、学术符号、黑白高反差、边缘能量、实时感。
- 画面气质：像一个正在运行的 AI 操作系统入口，而不是普通设置面板。
- 视觉强度：特效必须明确可见，不能只是轻微点缀；静态状态也要有层次、光泽和能量感。
- 品牌识别：使用现有问学 logo 与 “Ask °For Σverything” 字标，突出数学符号、几何黑白和 AI 感。

## 2. 核心色彩

底色以黑白灰建立高反差，彩色只做高能强调，但强调色必须足够亮、足够“电”。

### 2.1 中性色

- `background-light`: `oklch(0.985 0 0)`，冷白背景。
- `background-dark`: `oklch(0.13 0 0)`，近黑背景。
- `foreground-light`: `oklch(0.12 0 0)`，强黑正文。
- `foreground-dark`: `oklch(0.98 0 0)`，高亮白正文。
- `panel-light`: `oklch(1 0 0 / 0.82)`，半透明玻璃白。
- `panel-dark`: `oklch(0.18 0 0 / 0.72)`，半透明玻璃黑。
- `border-glass`: `oklch(1 0 0 / 0.38)`，玻璃高光边。
- `shadow-deep`: `rgb(0 0 0 / 0.28)`，深层投影。

### 2.2 能量色

- `electric-blue`: `oklch(0.72 0.18 245)`，主流光蓝。
- `laser-violet`: `oklch(0.72 0.22 305)`，AI 能量紫。
- `quantum-cyan`: `oklch(0.78 0.18 185)`，执行态青色。
- `signal-green`: `oklch(0.74 0.17 150)`，运行成功/就绪。
- `coral-pulse`: `oklch(0.76 0.18 35)`，警示、焦点跳动。
- `error-red`: `oklch(0.64 0.24 25)`，错误和 destructive。

### 2.3 渐变规则

- 主渐变必须是多色能量环：`electric-blue -> laser-violet -> quantum-cyan -> coral-pulse`。
- 不使用单一紫蓝渐变铺满背景；颜色要沿边缘、分割线、按钮光带、运行态框线流动。
- 大面积背景保持黑白灰玻璃质感，彩色负责“能量路径”。

## 3. 材质

问学 UI 的基础材质是 **Liquid Glass + Energy Edge**。

- 主面板：半透明玻璃，`backdrop-filter: blur(18px) saturate(160%)`。
- 面板边缘：双层边框，外层彩色能量线，内层白色玻璃高光。
- 内容区：背景可见轻微噪点、细网格、扫描线或符号纹理，不能是纯平面。
- Logo 区：必须有能量辉光，但辉光应沿 logo 边缘或文字后方扩散，不使用独立装饰圆球。
- 按钮：默认有玻璃反光、顶部高光线和 hover 光扫。
- 状态卡：运行态必须有动态边缘，错误态必须有红色脉冲边缘。

## 4. 字体与排版

- 中文与正文：系统栈 `system-ui, PingFang SC, Microsoft YaHei`。
- 版本号、路径、日志、技术标签：`ui-monospace`。
- 字号层级：
  - 主标题：20-24px / 700。
  - 状态标题：16-18px / 650。
  - 正文：14px / 400。
  - 辅助说明：12-13px / `muted-foreground`。
  - 技术元信息：10-11px / mono。
- 标题可以更锐利、更有科技感，但不要使用负字距。
- 关键数字、版本、状态名可以使用等宽字体增强控制台感。

## 5. 图形语言

- 品牌图形：优先使用现有 `logo.png`、`lightslogen.png`、`darkslogen.png`、`nobottomslogen.png`。
- 图标：使用 lucide-react，线性图标必须和能量线风格一致。
- 几何元素：允许使用细线框、角标、坐标点、分割线、扫描网格、数学符号暗纹。
- 禁止：卡通吉祥物、软萌插画、普通 SaaS 卡片堆、装饰性圆球、bokeh 背景。

## 6. 特效要求

特效是问学视觉语言的核心，不是可选装饰。

必须包含：

- Liquid Glass 边框：玻璃包边 + 彩色能量流动 + 内侧高光。
- Logo 能量场：logo 或字标背后有缓慢呼吸的多色辉光。
- 光扫按钮：主按钮 hover/active 时有横向扫光。
- 状态脉冲：`launching`、`running`、`error` 都有不同节奏的状态脉冲。
- 细粒噪点：背景或玻璃层叠加极轻噪点，增加质感。
- 扫描线/网格：暗纹级别存在，强化“AI 控制台”感。
- 数据闪烁：版本号、状态标签、步骤项可有轻微 shimmer 或 tick 动效。
- 进入动画：首屏元素分层进入，logo、主面板、状态区、底部信息依次出现。

## 7. 动效节奏

- 首屏进入：500-800ms，多层 stagger。
- 面板 hover：120-180ms，边缘高光增强。
- 主按钮 hover：180-260ms，光扫 + 轻微上浮。
- 状态切换：250-400ms，颜色、边框、文字同步过渡。
- 运行态流光：8-14s 循环，双层反向异速。
- 错误态脉冲：1.2-1.8s 循环，红色边缘呼吸。
- 减少动态效果开启时：停用循环动画，保留静态高光、玻璃材质和清晰状态色。

## 8. 状态色语义

- `idle`：黑白灰玻璃，少量蓝紫暗光，等待启动。
- `launching`：`coral-pulse` + `electric-blue` 交替，表现系统正在点火。
- `running`：`signal-green` + `quantum-cyan`，边缘流光最强，表现浏览器已接通。
- `error`：`error-red` + 暗红玻璃，边缘脉冲明显，但文字仍保持可读。

## 9. UI 观感底线

- 页面不能像默认 shadcn 示例，必须一眼有问学自己的“AI 能量玻璃”风格。
- 不能只有静态白卡片；至少要有玻璃材质、彩色边缘、光扫、背景纹理四类视觉层。
- 特效多，但信息必须清楚：状态、主按钮、版本、错误文本不能被光效遮挡。
- 深浅色都要成立；深色可以更炫，浅色也必须有玻璃折射和能量边线。
